# Fonts

Self-hosted variable fonts, Latin subset, from the fontsource packages
`@fontsource-variable/newsreader` and `@fontsource-variable/figtree` (5.3.0).
Both are licensed under the SIL Open Font License 1.1; the license texts are
beside the files. Newsreader is used for display and headings, Figtree for
body and controls. The optical size axis of Newsreader is not loaded yet; the
build step that introduces large display sizes should compare the opsz file.
